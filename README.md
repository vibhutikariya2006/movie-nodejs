# Movie Management API

A RESTful API built using Node.js, Express.js, and MongoDB to manage movie records. It supports CRUD operations, including adding, retrieving, updating, and deleting movies.

## Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose

## Features

* Add a new movie
* Get movie details by ID
* Update existing movie details
* Delete a movie
* Check for duplicate movies

## API Endpoints

| Method | Endpoint                      | Description       |
| ------ | ----------------------------- | ----------------- |
| POST   | `/api/movies/addmovie`        | Add a movie       |
| GET    | `/api/movies/getmovie/:id`    | Get a movie by ID |
| PUT    | `/api/movies/updatemovie/:id` | Update a movie    |
| DELETE | `/api/movies/deletemovie/:id` | Delete a movie    |
